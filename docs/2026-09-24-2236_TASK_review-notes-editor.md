## What's there now

- Double-click a block → a dialog with the cursor in its notes.
- One line per note. Enter = new line, Backspace on an empty line = remove.
- Click a line's **•** to cycle it: bullet → ☐ to-do → ☑ done → bullet.
- A block with notes shows **⋯** on the board. Printing adds a notes page.
- Regulars can carry default notes.
